NerosInsurge13

NerosInsurge13 is an app in active development by PriestH13, designed as a powerful platform for creating and managing petitions with built-in social and communication features.
It combines a petition system, global and private chat, user profiles, notifications, and a full REST API — all in a modular, secure architecture meant for experimentation, automation, and real-time interaction.

NerosInsurge13 lets users create petitions, sign them, comment, and participate in discussions.
It includes a global chat (for public conversations) and private chat between users, detailed profiles, live notifications, and API endpoints for developers.
The project aims to blend UX design, real-time systems, and cybersecurity practices into a single platform.

Key Features

✅ Create, edit, and delete petitions

✅ Signature system (with optional double opt-in email verification)

💬 Global chat for open discussions (messages, emoji, moderation)

✉️ Private one-to-one chat

💭 Petition comments with threading and moderation

👤 User profiles (avatar, bio, activity tracking)

🔔 Real-time notifications (new signature, comment, or message)

🔐 Secure authentication (registration, login, password reset)

🧩 RESTful API for petitions, comments, profiles, and chat

🧪 Ready for local development and testing

🔧 Modular architecture for future extensions (moderation, stats, integrations)

Tech Stack

Backend: Django + Django REST Framework

Realtime: WebSocket

Frontend: HTML5, CSS3 (custom), JavaScript

Database: SQLite (development)

Auth: Django built-in auth + token/JWT for API

Messaging: Redis

Environment: Debian GNU/Linux

NerosInsurge13

NerosInsurge13 è un’app in fase di sviluppo attivo creata da PriestH13, progettata come una piattaforma avanzata per creare e gestire petizioni, integrando al suo interno funzionalità social e di comunicazione.
Combina un sistema di petizioni, chat globale e privata, profili utente, notifiche e una REST API completa — tutto basato su un’architettura modulare e sicura, pensata per sperimentazione, automazione e interazione in tempo reale.

Con NerosInsurge13, gli utenti possono creare, firmare e commentare petizioni, oltre a partecipare a discussioni pubbliche e private.
Include una chat globale (per conversazioni pubbliche) e una chat privata tra utenti, profili dettagliati, notifiche in tempo reale, e endpoint API per sviluppatori.
L’obiettivo del progetto è unire design UX, sistemi in tempo reale e pratiche di cybersecurity in un’unica piattaforma moderna.

Funzionalità principali

✅ Creazione, modifica e cancellazione delle petizioni
✅ Sistema di firme (con opzione di verifica email double opt-in)
💬 Chat globale per discussioni aperte (messaggi, emoji, moderazione)
✉️ Chat privata uno-a-uno
💭 Commenti alle petizioni con thread e moderazione
👤 Profili utente (avatar, biografia, tracciamento attività)
🔔 Notifiche in tempo reale (nuove firme, commenti o messaggi)
🔐 Autenticazione sicura (registrazione, login, recupero password)
🧩 RESTful API per petizioni, commenti, profili e chat
🧪 Pronto per lo sviluppo e i test in locale
🔧 Architettura modulare per future estensioni (moderazione, statistiche, integrazioni)

Stack Tecnologico

Backend: Django + Django REST Framework
Realtime: WebSocket
Frontend: HTML5, CSS3 (personalizzato), JavaScript
Database: SQLite (ambiente di sviluppo)
Autenticazione: Sistema auth integrato Django + token/JWT per API
Messaggistica: Redis
Ambiente: Debian GNU/Linux
